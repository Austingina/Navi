# MapEditor 使用说明

基于 **Qt5 + PCL + OpenGL + CUDA** 的多子地图可视化编辑工具，用于在工程目录中加载、显示、编辑并保存多楼层地图数据（子地图点云、语义点、传送门、路线等）。

---

## 1. 地图工程目录约定

工程以**文件夹**为单位读写。

| 规则 | 说明 |
|------|------|
| 主配置 | 在所选目录下，文件名为 **`<目录名>.json`**。例如目录为 `/data/maps/building_a`，则配置文件为 `/data/maps/building_a/building_a.json`。 |
| 点云 | `submaps` 里各子地图的 `map_file` 为相对该目录的路径（如 `submaps/floor1.pcd`），程序会拼接为绝对路径加载/保存。 |
| 全局 | JSON 中 `global.default_submap` 指定全局参考子地图 ID；**保存前必须存在且有效**，否则将提示并阻止保存。 |

保存时会对 JSON 做**紧凑排版**（如 `position` / `orientation` / `translation` / `rotation` 尽量单行），并将 pose 分量里原本为整数的形式写成带一位小数的浮点（如 `0` → `0.0`），便于与部分下游解析器兼容。

---

## 2. 系统要求与依赖

- **操作系统**：Ubuntu 20.04 / 22.04 等（与 Qt5、PCL 环境一致即可）。
- **Qt**：5.12+（Widgets、OpenGL）。
- **PCL**：1.10+（common、io、filters、registration）。
- **Eigen** 3.3+、**OpenGL** 3.3+。
- **CMake** 3.18+。
- **CUDA 工具链**：与 `gpu_bbs3d` 一致；工程启用 **CUDA** 编译 `BBS3DWrapper.cu`。
- **gpu_bbs3d**：需已安装到系统（默认查找 `/usr/local/include`、`/usr/local/lib`）。子地图对齐中的 **3D-BBS 粗匹配在 GPU 上执行**；对齐阶段 BBS **不设超时**（可跑至完成）。

若未安装 `gpu_bbs3d`，CMake 会报错并提示先编译安装 3D-BBS 相关库。

---

## 3. 编译与运行

```bash
cd /path/to/Navi/MapEditor
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
```

```bash
./MapEditor
```

启动后通过 **文件 → 打开**（或工具栏「打开」）选择**地图目录**（不是单个 JSON 文件）。**保存 / 另存为** 同样针对目录：首次保存或「另存为」时选择目标目录后，会在该目录下写入 `<目录名>.json` 与各 PCD。

---

## 4. 界面概览

- **左侧「子地图管理」**：子地图树、每条子地图下的「地图点云 / 语义点位 / 传送门」勾选、路线列表；支持右键菜单与拖拽。
- **中央 3D 视图**：点云、坐标轴、网格、语义点与传送门标记、路线折线、对齐时的裁剪框线框。
- **右侧「属性编辑」**：当前选中子地图、语义点、传送门的属性。
- **菜单 / 工具栏**：打开、保存、另存为、新增 Submap、重置视角；工具栏还可设置**全局显示降采样体素（米）**并点击「应用」——仅影响显示与性能，**不改变磁盘上的 PCD 精度**。

---

## 5. 子地图与显示控制

- **默认子地图**：在某一子地图节点上右键 → **设为默认子地图**。名称旁会显示 ⭐。对齐时 **目标点云** 优先使用该子地图；若未设置，程序会尝试选用其他子地图，但**保存前仍须手动设置有效的 `default_submap`**。
- **主开关**：勾选子地图根节点时，会同步勾选/取消 **地图点云、语义点位文件夹、传送门文件夹** 三项，并统一控制点云显示与两类标记的显示。仍可单独勾选子项做细粒度控制。
- **子地图 ID**：界面中会展示子地图标识，便于与 JSON 配置对应。
- **颜色与点大小**：在属性面板中调整（用于区分各 submap）。

---

## 6. 子地图对齐：三种交互方式

全局约定：**变换 `transform` 表示该子地图点云从本地坐标系到 `default_submap` 坐标系的刚体变换**。对齐前请设好 **默认子地图**（⭐），并保证参与匹配的子地图均已加载点云。

下面三种方式可单独使用，按数据情况选择；方式一、二共用同一对话框 **对齐 Transform (3D-BBS)**（右键待对齐子地图打开），方式三在属性面板完成。

### 6.1 方式一：使用默认配置做点云匹配（最少操作）

适用于：场景尺度与默认参数接近、初始位姿大致在原点附近，或只想快速试跑一次匹配。

1. 确认 **默认子地图** 为目标参考图，且与待对齐子地图在 3D 视图中可见。  
2. 在待对齐子地图上右键 → **对齐 Transform (3D-BBS)**。  
3. **不修改** 对话框内「目标点云 / 源点云 / 3D-BBS / GICP」各控件的数值（即使用程序内置默认值）。  
4. **初始位置**：对话框打开后，「初始位置」一栏会显示默认 **(0, 0, 0)**（全局坐标）。若你的地图以原点附近为参考，可直接点击 **开始对齐**；若新图实际在场景其它区域，仍建议点击 **在地图上选择点**，在 **默认子地图** 点云上点一下，再 **开始对齐**。  
5. 匹配成功后的 **预览 / 应用结果 / 取消回退** 与下文「方式二」相同（见 §6.3）。

**当前默认参数一览（未改旋钮时）**  

| 分组 | 项 | 默认值（约） |
|------|----|----------------|
| 目标点云 | XY 搜索范围 | 100 m |
| 目标点云 | Z 搜索范围 | 20 m |
| 源点云 | 裁剪中心 | (0, 0, 0)（源子地图局部坐标） |
| 源点云 | 裁剪立方边长 | 20 m |
| 源点云 | BBS 降采样 | 0.5 m |
| 3D-BBS | 最细层分辨率 | 1.0 m |
| 3D-BBS | 体素层级数 | 6 |
| 3D-BBS | 最低匹配得分 | 0.1 |
| GICP | 最大 fitness 阈值 | 1.2 |

---

### 6.2 方式二：使用点云匹配参数配置（精细调参）

适用于：搜索范围与默认差异大、源图需换裁剪中心、BBS/GICP 需收紧或放宽、希望先看裁剪范围再跑匹配。

1. 同样右键待对齐子地图打开对齐对话框。  
2. **初始位置（目标子地图）**  
   - 点击 **在地图上选择点**，在 **默认子地图** 点云上点击，给出新图在全局中的**粗位置**（BBS 在该位置附近的「目标点云」子区域内搜索）。  
3. **目标点云**  
   - **XY / Z 搜索范围**：以初始位置为中心，在目标点云中参与搜索的半尺寸（米）；过大变慢、过小易漏真解。  
4. **源点云**  
   - **裁剪中心**：默认原点；若有效结构不在源图中心，点 **在地图上选择裁剪中心**，在 **当前待对齐（源）子地图** 点云上选中心（程序会换算到源子地图局部坐标）。  
   - **裁剪范围**：立方体边长，决定送入匹配的源点云块大小。  
   - **BBS 降采样**：体素大小，影响速度与细节。  
5. **3D-BBS**  
   - **最细层分辨率 / 体素层级数 / 最低匹配得分**：控制金字塔分支定界行为；得分阈值过高可能导致无解。  
6. **GICP**  
   - **最大 fitness 阈值**：粗匹配后 GICP 的通过标准；过严易判失败，过松可能接受错误位姿。  
7. **预览裁剪框（推荐）**  
   - 点击 **预览裁剪框**：3D 视图中 **青色线框** 为目标搜索区域，**黄色线框** 为源裁剪区域（源框会按当前子地图 `transform` 画在世界系中）。确认范围合理后再 **开始对齐**。  
8. **开始对齐** → 进度与状态在对话框内显示；成功后见 §6.3。

---

### 6.3 点云匹配成功之后（方式一、二共用）

1. 匹配成功时，视口会 **立即预览** 应用新 `transform` 后的点云与标记；若裁剪框仍开启，**源裁剪框会随新变换更新**。  
2. 点击 **应用结果**：将结果写入该子地图的 `transform` 并关闭对话框。  
3. 点击 **取消**：若曾进入成功预览，会 **恢复打开对话框前的 `transform`**，并清除裁剪框等临时状态。  
4. **保存** 工程目录以持久化 JSON。

**前置条件简述**：至少两个子地图且均有点云；目标点云来自 **默认子地图**（若未设置默认，程序会尝试另选子地图，但保存工程前仍须设置合法的 `default_submap`）。

---

### 6.4 方式三：直接指定 Transform（不用点云匹配）

适用于：已知精确外参（如标定、其它 SLAM 输出）、仅做微调、或匹配失败时手工填入。

1. 在左侧树中 **单击选中** 要修改的子地图（不是仅展开，需选中该子地图节点）。  
2. 在右侧 **属性编辑** 面板找到分组 **「变换 (Transform → default_submap)」**。  
3. 编辑 **平移** `tx, ty, tz`（米）与 **四元数** `qx, qy, qz, qw`（旋转；程序在 **应用修改** 时会做归一化）。含义与工程 JSON 中 `submaps.<id>.transform` 的 `translation` / `rotation` 一致。  
4. 可同时改名称、描述、显示颜色、体素与点大小等；改完点 **应用修改**。  
5. 3D 视图会刷新该子地图位姿与语义点等；**保存** 目录写入文件。

此路径 **不会** 打开 3D-BBS 对话框，也完全依赖你输入的数值正确性；若与真实重叠不符，请改回方式一或二重新匹配。

---

## 7. 语义点位与传送门

- **添加**：子地图或「语义点位 / 传送门」文件夹上右键 → **添加语义点位** 或 **添加传送门**，然后在 **对应子地图点云** 上左键点击。按提示输入名称；传送门还需选择目标子地图。传送门会关联同名语义点（若不存在会自动创建）。  
- **编辑**：在树中选中语义点或传送门，在右侧属性面板修改。  
- **移动**：在 3D 视图中将鼠标移到黄色语义点标记上，**长按左键**进入拖拽，可在场景中调整位置（当前实现主要更新 `single_pose` 的第一个位姿）。  
- **提示**：鼠标悬停在标记上时，会显示类型、子地图 ID 与名称的 **工具提示**。

---

## 8. 路线（Routes）

- **新增路线**：在左侧 **路线 (Routes)** 根节点上右键 → **添加路线**，输入名称。  
- **添加途径点**：从树中 **拖动某个语义点** 到目标 **路线节点** 或 **路线下的某一途径点** 上释放，即在对应位置插入一个 waypoint（引用该子地图 + 语义点名称）。  
- **显示**：每条路线可单独勾选显示；3D 中按途径点顺序连接成 **彩色折线**（至少两个有效途径点时可见）。  
- **删除路线**：在路线节点上右键 → **删除此路线**。  

重建树形结构（如导入、对齐、增删点后）会尽量 **保持子地图与路线的展开状态**，减少反复展开的操作。

---

## 9. 新增与删除子地图

- **新增**：菜单 **编辑 → 新增 Submap**、工具栏 **+ Submap** 或左侧面板按钮；支持导入 PCD 或 PCD+JSON，子地图 ID 不可与现有重复。  
- **删除**：非默认子地图可在右键菜单中删除；**不能删除当前默认子地图**。

## 12. 常见问题

- **无法保存**：检查是否已设置 **默认子地图**，且其 ID 在子地图列表中存在。  
- **对齐失败**：缩小搜索范围或调整 BBS/GICP 参数；确认初始点在目标地图上位置合理、源裁剪包含足够结构特征。  
- **找不到 gpu_bbs3d**：按 CMake 提示安装库并保证头文件与 `.so` 在 `/usr/local` 或自行修改 `CMakeLists.txt` 中的搜索路径。

如有与导航栈约定的 JSON 字段名或旧版 `multifloor.json` 文件名习惯，只要将文件按 **目录名.json** 放入同名目录并保证内部结构与程序读写一致即可兼容当前编辑器。
