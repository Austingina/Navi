# MCP导航接口文档

## 概述

本文档描述了基于FastMCP框架的机器人导航系统接口，提供了完整的导航功能，包括目标设置、状态查询、等待到达等功能。

---

## 1. set_goal

**功能**：下发导航目标点（通过预设点名称）

**描述**：从预设的语义地图中选择目标点进行导航

**参数**：

| 参数名   | 类型   | 必填 | 说明                   |
|----------|--------|------|------------------------|
| target   | str    | 是   | 目标点名称（需在预设地图中） |

**可用目标点**：狗巢、配电房、灭火器箱、液晶大屏、会议桌

**返回值**：

| 字段      | 类型   | 说明                       |
|-----------|--------|----------------------------|
| success   | bool   | 操作是否成功               |
| msg       | str    | 操作结果说明               |
| target    | str    | 实际下发的目标点名称（成功时） |

**使用示例**：
```json
// 请求
{
  "target": "狗巢"
}

// 响应（成功）
{
  "success": true,
  "msg": "目标 狗巢 已下发",
  "target": "狗巢"
}

// 响应（失败）
{
  "success": false,
  "msg": "目标点 未知点 不在白名单中"
}
```

## 2. set_goal_by_lonlat

**功能**：根据经纬度导航到目标点附近

**描述**：输入GPS经纬度坐标，系统自动转换为地图坐标并导航至指定距离的位置

**参数**：

| 参数名    | 类型   | 必填 | 默认值 | 说明                         |
|-----------|--------|------|--------|------------------------------|
| lon       | float  | 是   | -      | 目标点经度                   |
| lat       | float  | 是   | -      | 目标点纬度                   |
| distance  | float  | 否   | 1.5    | 距离目标点的距离（米）       |

**返回值**：

| 字段            | 类型   | 说明                                   |
|-----------------|--------|----------------------------------------|
| success         | bool   | 操作是否成功                           |
| target_str      | str    | 实际下发的目标点描述                   |
| msg             | str    | 操作结果说明                           |
| original_target | dict   | 原始目标点经纬度及转换后坐标           |
| actual_target   | dict   | 实际下发的目标点坐标                   |
| distance        | float  | 距离目标点的距离                       |

**使用示例**：
```json
// 请求
{
  "lon": 116.3974,
  "lat": 39.9093,
  "distance": 2.0
}

// 响应
{
  "success": true,
  "target_str": "lonlat(116.3974,39.9093)_dist_2.0",
  "msg": "已下发目标，将在距离经纬度(116.3974, 39.9093)约2.0米处停下并面向目标点",
  "original_target": {
    "lon": 116.3974,
    "lat": 39.9093,
    "x": 123.45,
    "y": 67.89
  },
  "actual_target": {
    "x": 121.45,
    "y": 65.89
  },
  "distance": 2.0
}
```

## 3. set_goal_by_xy

**功能**：根据地图坐标导航到目标点附近

**描述**：直接使用地图坐标系坐标进行导航

**参数**：

| 参数名    | 类型   | 必填 | 默认值 | 说明                         |
|-----------|--------|------|--------|------------------------------|
| x         | float  | 是   | -      | 目标点X坐标（地图坐标系）    |
| y         | float  | 是   | -      | 目标点Y坐标（地图坐标系）    |
| distance  | float  | 否   | 1.5    | 距离目标点的距离（米）       |

**返回值**：

| 字段            | 类型   | 说明                                   |
|-----------------|--------|----------------------------------------|
| success         | bool   | 操作是否成功                           |
| target_str      | str    | 实际下发的目标点描述                   |
| msg             | str    | 操作结果说明                           |
| original_target | dict   | 原始目标点坐标                         |
| actual_target   | dict   | 实际下发的目标点坐标                   |
| distance        | float  | 距离目标点的距离                       |

**使用示例**：
```json
// 请求
{
  "x": 10.5,
  "y": 8.2,
  "distance": 1.0
}

// 响应
{
  "success": true,
  "target_str": "xy(10.5,8.2)_dist_1.0",
  "msg": "已下发目标，将在距离(10.5, 8.2)约1.0米处停下并面向目标点",
  "original_target": {
    "x": 10.5,
    "y": 8.2
  },
  "actual_target": {
    "x": 9.8,
    "y": 7.6
  },
  "distance": 1.0
}
```

## 4. get_pose_list

**功能**：获取所有预设点名称

**描述**：返回系统中所有可用的预设导航点

**参数**：无

**返回值**：

| 字段    | 类型     | 说明               |
|---------|----------|--------------------|
| success | bool     | 操作是否成功       |
| keys    | list     | 预设点名称列表     |
| count   | int      | 预设点数量         |
| msg     | str      | 错误信息（失败时） |

**使用示例**：
```json
// 响应
{
  "success": true,
  "keys": ["狗巢", "配电房", "灭火器箱", "液晶大屏", "会议桌"],
  "count": 5
}
```

## 5. get_status

**功能**：获取小车实时状态（位置、姿态）

**描述**：返回机器人当前的位置和姿态信息

**参数**：无

**返回值**：

| 字段        | 类型   | 说明                       |
|-------------|--------|----------------------------|
| success     | bool   | 操作是否成功               |
| position    | dict   | 当前位置（x, y, z）         |
| orientation | dict   | 当前姿态（四元数x, y, z, w）|
| msg         | str    | 错误信息（失败时）          |

**使用示例**：
```json
// 响应
{
  "success": true,
  "position": {
    "x": 5.23,
    "y": -2.17,
    "z": 0.0
  },
  "orientation": {
    "x": 0.0,
    "y": 0.0,
    "z": 0.707,
    "w": 0.707
  }
}
```

## 6. wait_goal_reached

**功能**：阻塞直到到达目标点或超时

**描述**：异步等待机器人到达目标点，支持自定义精度和超时设置

**参数**：

| 参数名        | 类型   | 必填 | 默认值 | 说明                       |
|---------------|--------|------|--------|----------------------------|
| target        | str    | 是   | -      | 目标点名称                 |
| timeout       | float  | 否   | 60.0   | 超时时间（秒）             |
| xy_tolerance  | float  | 否   | 0.5    | 位置容差（米）             |
| yaw_tolerance | float  | 否   | 0.1    | 朝向容差（弧度）           |

**返回值**：

| 字段      | 类型   | 说明                       |
|-----------|--------|----------------------------|
| success   | bool   | 是否到达目标               |
| msg       | str    | 结果说明                   |
| timestamp | int    | 到达时的时间戳（成功时）    |

**使用示例**：
```json
// 请求
{
  "target": "狗巢",
  "timeout": 120.0,
  "xy_tolerance": 0.3,
  "yaw_tolerance": 0.05
}

// 响应（成功）
{
  "success": true,
  "msg": "已到达目标 狗巢",
  "timestamp": 1695123456
}

// 响应（超时）
{
  "success": false,
  "msg": "等待超时或未到达"
}
```

## 7. get_nearest_point

**功能**：获取当前位置最近的预设点

**描述**：计算并返回距离当前位置最近的预设导航点

**参数**：无

**返回值**：

| 字段            | 类型   | 说明                                   |
|-----------------|--------|----------------------------------------|
| success         | bool   | 操作是否成功                           |
| nearest_point   | str    | 最近的预设点名称                       |
| distance        | float  | 最近点距离（米）                       |
| current_position| dict   | 当前位置（x, y）                        |
| all_distances   | dict   | 所有预设点到当前位置的距离              |
| msg             | str    | 结果说明                               |

**使用示例**：
```json
// 响应
{
  "success": true,
  "nearest_point": "狗巢",
  "distance": 2.456,
  "current_position": {
    "x": 5.23,
    "y": -2.17
  },
  "all_distances": {
    "狗巢": 2.456,
    "配电房": 5.123,
    "灭火器箱": 8.901,
    "液晶大屏": 12.345,
    "会议桌": 15.678
  },
  "msg": "当前位置最接近的预设点是: 狗巢 (距离: 2.456m)"
}
```

## 错误处理

所有接口遵循统一的错误处理格式：

```json
{
  "success": false,
  "msg": "具体的错误信息"
}
```

常见错误类型：
- `无实时位姿数据`：机器人定位系统未就绪
- `目标点不在白名单中`：指定的目标点不存在
- `超出地图边界`：目标坐标超出允许范围
- `等待超时或未到达`：导航超时或失败

---

## 坐标系说明

- **地图坐标系（map）**：固定的世界坐标系，用于全局定位
- **里程计坐标系（odom）**：基于里程计的局部坐标系
- **GPS坐标系**：WGS84经纬度坐标，自动转换为地图坐标

---

## 使用流程建议

1. **获取预设点列表**：使用 `get_pose_list` 查看可用目标
2. **获取当前状态**：使用 `get_status` 确认机器人位置
3. **设置导航目标**：
   - 预设点导航：使用 `set_goal`
   - GPS导航：使用 `set_goal_by_lonlat`
   - 坐标导航：使用 `set_goal_by_xy`
4. **等待到达**：使用 `wait_goal_reached` 阻塞等待结果
5. **查找最近点**：使用 `get_nearest_point` 获取最近的预设点
